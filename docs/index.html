Analytics Engineering · Governança · BI

Governed Analytics Platform

Contexto: dados de e-commerce sem controle de qualidade, rastreabilidade e critério claro de publicação podem chegar ao consumo analítico mesmo quando ainda apresentam problemas, elevando o risco de decisões tomadas sobre dados inconsistentes.

Ação: construí uma plataforma de Analytics Engineering com Python, SQL, dbt, DuckDB e PostgreSQL, organizada em 4 camadas de dados, 3 estados de publicação e 7 workflows de GitHub Actions, incorporando Data Contracts, Data Quality Gates, Data Lineage, Privacy Risk Score e Publication Gate.

Resultado: o Publication Gate aprova, envia para revisão ou bloqueia dados antes da camada publicada, enquanto mais de 900 testes automatizados ajudam a garantir que mudanças de interface ou evolução do código não alterem silenciosamente regras de qualidade e governança.

Resumo: uma plataforma governada que transforma dados brutos em dados publicáveis somente após critérios explícitos de qualidade, privacidade e rastreabilidade.

Automação · Operações · BI

Central de Automação e Operações

Contexto: operações com múltiplos workflows podem perder visibilidade de SLA, backlog, criticidade e gargalos quando as informações ficam dispersas e exigem acompanhamento manual.

Ação: desenvolvi uma solução analítica com Python, SQL e Streamlit para consolidar workflows, indicadores operacionais, regras de criticidade, alertas e integração com Pipefy via API/GraphQL.

Resultado: a solução concentra em uma única visão o que exige atenção operacional, ajudando a priorizar itens críticos e evitando que atrasos, gargalos e violações de SLA fiquem escondidos em controles separados.

Resumo: dados operacionais transformados em uma visão única para acompanhamento, priorização e ação.

AWS · Serverless · Cloud

AWS Serverless Access Counter

Contexto: o projeto precisava registrar acessos a uma aplicação web sem depender da manutenção de servidores dedicados.

Ação: durante o AWS re/Start, construí uma arquitetura serverless utilizando 10 serviços AWS para entrega web, API, processamento, persistência, segurança, observabilidade, notificações e controle de custos.

Resultado: a solução demonstra uma arquitetura orientada a eventos com persistência e monitoramento integrados, eliminando a necessidade de manter um servidor dedicado apenas para contabilizar acessos.

Resumo: contador de acessos serverless com entrega, segurança, persistência, observabilidade e custos tratados na própria arquitetura AWS.
