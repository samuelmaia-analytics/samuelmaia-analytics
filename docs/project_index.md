# Project Index

## Recommended Visibility Order (Updated)

### Flagship

1. `Governed-Analytics-Platform`
   Governed analytics publishing platform with contracts, quality controls, lineage, and controlled publication gates. Portfolio project with explicit validation scope and documented limits.

### Core

2. `azure-databricks-governed-lakehouse`
   Lakehouse pipeline with Raw/Bronze/Silver/Gold/Quarantine layers, explicit schemas, validations, and publication gates. Local execution documented; cloud execution remains planned.

3. `central-automacao-operacoes`
   Operational automation hub integrating Pipefy (API/GraphQL) to consolidate SLA, backlog, criticality rules, and alerts, with demonstrative mode when credentials are not available.

### Complementary

4. `aws-serverless-access-counter`
   AWS re/Start group project: static frontend + Lambda (Python) counter with DynamoDB and documented architecture/security/observability components.

5. `churn-prediction`
   Churn prediction repository focused on features, training/inference, prioritization, and drift monitoring (PSI/KS).

6. `revenue-intelligence-platform-suite`
   Revenue analytics suite showcasing governed metrics, semantic layer thinking, and pipeline/observability tooling.

### Supporting / Legacy

Keep older or generic repositories visible only when they add historical depth, not as lead assets.
